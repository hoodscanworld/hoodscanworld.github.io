# HOODSCAN

**AI-Native Trading Intelligence Platform**

HOODSCAN is the web interface and demo platform for the [robinhood-for-agents](https://github.com/kevin1chun/robinhood-for-agents) MCP server — rebranded and extended with wallet-native authentication, a full product dashboard, and a public-facing demo.

## Features

- 50 MCP tools for any MCP-compatible AI agent
- 70+ async TypeScript client methods
- Native support for Claude Code, Codex, OpenClaw
- MetaMask + Phantom wallet authentication
- Self-renewing Robinhood sessions
- Options scanner, portfolio tracker, real-time quotes

## Live Site

Visit [hoodscanworld.github.io](https://hoodscanworld.github.io)

## Tech Stack

- React 19 + Vite 8
- TypeScript 6
- Tailwind CSS v4
- Framer Motion
- React Router v7
- GitHub Pages
